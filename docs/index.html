六祖大师法宝坛经
十 品 圆 满
十品圆满。总序、凡例之后，依敦煌本顺释行由、般若、疑问、定慧、坐禅、忏悔、机缘、顿渐、护法、付嘱十品。底本用敦煌本 S.5475。

《坛经》是唯一一部由中国人所说、被尊为「经」的佛典。本书以敦煌本为底本，依「三才五蕴太极空杯」「阴阳太和」「和合之辨」与《金刚经》般若范式逐品通释：破执在金刚，归心在坛经。
