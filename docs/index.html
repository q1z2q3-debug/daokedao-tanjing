这本书主张什么

「自性」不是一个独立恒常的实体，是般若空性在众生分上的本名。自性五句（何期自性本自清净／本不生灭／本自具足／本无动摇／能生万法）说的不是五个属性，是同一件事的五个面：本自具足，所以不必外求；本无动摇，所以风幡之争勘不出胜负。

「和合之辨」是全书判定尺：和是本自圆满、无边界、无对待的实相；合是因缘构框、划分边界、二元对立、取舍抓取的造作。凡把一体割为两边、另立一个可抓取的目标（包括把「空」「静」「次第」「顿」做成可抓取之物）者，皆判为合。

不支持狂禅，也不支持枯禅：自性具足是性体本圆，不代表无需去蔽；无念不是压念断念，是念起而不黏。
