卷首

总序与凡例

破执在金刚，归心在坛经。无住是体，自性是用；般若是眼，坛经是足。

总序

一、立旨：何为《坛经》，何为本次通释

《六祖大师法宝坛经》，是中国禅宗唯一一部由僧人口述、被后世尊为「经」的典籍。

佛典浩如烟海，唯此一经，是中国人的成佛之路、是般若落地的日用真心。

外来佛法，以《金刚经》破相、《心经》显空；唯独《坛经》，把空性转为自性，把经典转为本心，把修行转为生活。

本经最大特质：不崇玄妙、不求他佛、不执苦修、不落枯定。只教人自见本心、自成佛道。

本次《润泽说·坛经通释》，不取宗门语录机锋戏论，不取后世宗门派系附会，全程锚定「易—道—佛三参统一框架」，以：

1. 三才五蕴太极空杯模型 勘破五蕴、空性、缘起；

2. 阴阳太和体系 统摄动静、风幡、有无、阴阳对待；

3. 和合之辨 区分「人为造作之合」与「本然圆满之和」；

4. 《金刚经》「无住、无得、非心」正宗般若 校准全部见地。

以此四维，彻解六祖全部开示，令禅宗见地，完全回归大乘般若本源，不偏空、不落有、不落狂禅、不落执相。

二、全书核心宗旨

《金刚经》讲「无住以破执」，《坛经》讲「自性以成真」。

金刚经，破一切相、一切法、一切心，教人无所住；坛经，立自性具足、自性能生万法，教人自归家。

无住是体，自性是用；般若是眼，坛经是足。二者合一，方是完整佛法。

三、本次解读 七大定规

1. 底本纯正

以敦煌本《坛经》（S.5475）为正文底本，不杂惠昕本、宗宝本后人增删文句；异文、伪文、后世附会，全部单独校注，不混入正文义理。

2. 体系统一

所有解读，完全对接心经、金刚经、周易、道德经整套润泽道可道体系：五蕴解读必用「杯底色、四壁受想行识」原型模型；动静解读必用「阴幡阳风、太和本心」；修行解读必分「和／合」边界；般若解读必对标「应无所住、此心非心、三心不可得」。全书义理自洽、跨典互通、无矛盾、无偏差。

3. 义理校准：杜绝两大禅病

市面上坛经解读，终生两种大病：病一，狂禅——执本自具足，便废修行、废戒律、废次第，以为当下即是、无需用功；病二，枯禅——执空灭念、压止念头，以为一念不起即是禅。

本次通释彻底勘正：具足是性体圆满，修行是去蔽显真；空性是无住不执，不是断灭无念。

4. 核心框架固定

体：本自具足、不生不灭、自性太和。相：五蕴缘起、阴阳对待、动静相生。用：无住生心、随缘照了、日用即道。体、相、用三层，贯穿每一品、每一段公案。

5. 公案不讲故事，只讲见地

风幡公案、衣钵公案、南北禅公案，不聊历史戏说，不参人物情绪，只勘背后心性层级与般若义理。

6. 坚持「三参互证」

每段经文，必完成三层互参：参佛，对标金刚、心经般若；参道，对标老子自然无为；参易，对标阴阳、太和、保合正道。

7. 区分「指与月」

六祖全部言语，皆是指月之指；自性本心，是所指之月。绝不执文字为道、不执机锋为悟。

四、全书总纲

自性本自圆满（和），因执五蕴对立而成迷（合）；以无住之心破除二元，回归阴阳太和，即是成佛。

迷：住相、住空、住阴阳、住是非、住我法。悟：不住五蕴、不住空境、不落阴阳两端、本心太和如如。

此即整部《坛经》的终极内核。

五、全书结构

本书依敦煌本，逐品顺释：

1. 行由品第一（求法、两偈、三更传法、风幡勘验）

2. 般若品第二（摩诃般若、自性真空、无念之行）

3. 疑问品第三（自性净土、功德辨、在家修行）

4. 定慧品第四（定慧一体、无住无相无念）

5. 坐禅品第五（破看心看净、外离相内不乱）

6. 忏悔品第六

7. 机缘品第七

8. 顿渐品第八

9. 护法品第九

10. 付嘱品第十

（初稿定序时曾误记「忏悔品第五」，与后文「坐禅品第五」抵牾；今依宗宝十品次第改正，坐禅为第五，忏悔为第六。）

每一品皆含：原文底本｜时代背景｜字源溯源｜逐段深解｜体系联动｜和合对照｜跨典互参｜小结。

六、结序

西来般若，至《金刚》而尽破；中华禅心，至《坛经》而立极。

破执在金刚，归心在坛经。

今依「易道佛三参、阴阳太和、空杯模型、和合之辨」，正本清源、归宗般若，重释六祖坛经，令千古禅心，复归光明、落地日用。

是为序。

凡例

一、底本

本经正文以敦煌本《六祖坛经》（S.5475）为优先底本，文字依敦煌卷原文誊录。惠昕本、契嵩本、宗宝本等后世增改版本，不纳入正文；异文、增补段落、后人附会内容，在【校注】栏标出，不作正文采信。若不同版本文句差异直接影响义理，另设【异义辨析】专项说明。

品题（行由品第一至付嘱品第十）依通行十品立目，敦煌本原不分品；立目只为便于阅读，不改动经文文字。

二、体例固定

每一段经文的解读模块依次为：原文底本｜时代背景｜字源溯源｜逐段深解｜体系联动｜和合对照｜跨典互参｜小结。

三、核心名相，全书一以贯之

  • 五蕴：色为杯底，受、想、行、识为四壁；因缘聚则器相现，因缘散则器相消；空性超越器相边界，芥子纳须弥。
  • 阴阳太和：有形显相为阴，无形动能为阳；太和不是阴阳之外另立一物，是阴阳本未割裂的本然状态。
  • 和合之辨：「和」为本自圆满、无边界、无对待的实相；「合」是因缘构框、划分边界、二元对立、取舍抓取的造作。
  • 无住生心：此心非心，故名此心；不住五蕴之相，亦不住枯空之境。
  • 自性：即般若空性在众生分上的本名，不是一个独立恒常的实体。

四、校注符号

〔〕补字（敦煌本残损、缺字，依文义补足）；（）异文（他本不同文字）；△义理提示，后文专题展开；＊重要名相，首次出现重点溯源，后文不再赘述。

五、配图

沿用心经图式：核心譬喻图（三才五蕴空杯图、风幡阴阳太和图）；示意图只辅助见地，不替代文字；不绘神像、祖师画像，避免落相执。

六、义理校准

以般若为根本标尺，以《金刚经》「凡所有相，皆是虚妄」、《心经》「五蕴皆空」为基准。不支持狂禅：自性具足是性体本圆，不代表无需去蔽、不加护持。不支持枯禅：无念不是压念断念，是念起而不黏、不执。顿渐之辨：顿是见性一关，渐是保任除习，二者不相妨，不可偏废。

七、引用与三参

参佛以般若系经典校准，凡禅语皆回向无住、破相；参道取老子自然无为，不附会长生术数；参易取阴阳、保合太和，不取卜筮吉凶。

八、行文

重在见地厘清，不做文学抒情、故事戏说。公案勘心，不以猎奇机锋为趣。全部阐释服务于「自见自性、无住离执」这一宗旨。
